# Trendyol Torbasız Süpürge Görsel 1

Bu public repo, 23 Trendyol ürün satırı için model-doğru `Görsel 1` dosyalarını barındırır.

- Boyut: 1200 × 1800 px
- Format: RGB JPEG
- Dosya adları: exact model kodu + `_G1_GPTImage2.jpg`
- Ürün sırası ve SHA-256 değerleri: `manifest.json`
- Model → raw URL eşlemesi: `url_map.json`

Görseller, kullanıcı tarafından sağlanan/resmî OEM ürün kaynaklarıyla model, renk, gövde ve aksesuar düzeyinde karşılaştırılmıştır.
